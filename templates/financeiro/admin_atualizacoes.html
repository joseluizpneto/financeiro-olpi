Como ativar o agente no servidor (Docker Compose)

O container não acessa o socket do Docker diretamente. Para aplicar atualizações pelo painel, sincronize uma vez e adicione o worker ao cron do host:

./scripts/atualizar.sh --sync
* * * * * cd /caminho/do/projeto && ./scripts/atualizar.sh --daemon >> data/atualizacao/cron.log 2>&1
